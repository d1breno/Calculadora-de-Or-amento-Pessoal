# 📊 Calculadora de Orçamento Pessoal

Um projeto simples de calculadora de orçamento pessoal que permite adicionar transações de renda e despesas, calcular o saldo e exibir um resumo do orçamento de forma clara e interativa.

---

## 📝 Funcionalidades

- Adicionar transações com descrição e valor (positivo para rendas e negativo para despesas).
- Exibir resumo financeiro com:
  - Total de Renda.
  - Total de Despesas.
  - Saldo Atual.
- Lista de transações categorizadas por tipo (renda ou despesa).
- Interface amigável e responsiva.

---

## 🚀 Tecnologias Utilizadas

- **HTML**: Estrutura semântica do projeto.
- **CSS**: Estilização moderna e responsiva.
- **JavaScript**: Lógica para manipulação do DOM, cálculos financeiros e interatividade.
